# Reading boundary

- Public exports live only in `index.ts`; API DTO imports are type-only. Bridge owns credentials, repository owns durable reading decisions/outbox, root SW owns shell/control only. Staging workers may write only `sources`/`sourceChunks`; no second queue.
- KOSync is an external opaque HTTP protocol; XPointer restoration is a separate KOReader/CRengine contract. Preserve server IDs, history and wire shapes. Match upstream partial-MD5 offsets including short reads; keep full-original SHA-256 separate. Generate every new path from direct same-namespace siblings, retaining authored anchors; require exact primary source/CFI round trips. Incoming historical strings remain byte-exact with child-first/legacy fallback reading; never bulk rewrite history or auto-start after unsupported restoration.
- Original EPUBs use disk-backed Blob ranges/256 KiB IDB chunks, never whole-book buffers/maps. Reuse Blob BYOB backing; hash chunks without another source copy. Entry output has one bounded allocation. Native raw-DEFLATE feeds are 256 bytes with concurrent consumption; target-browser raw-decoder support needs qualification. Retire consumed IDB/index/native buffers through acknowledged ownership transfer into <=8 MiB workers; terminate on rotation/completion/abort. Serial small reads/writes alone retained book-sized unforced backing storage.
- Publish source/index/integrity/book/checkpoint atomically after sequential complete validation. `books.bytes` is null for new books: availability follows `sourceId` + complete source, not Blob presence. Never mint a missing manifest integrity hash on open. Normal reopen checks metadata/touched chunks, not the whole book; explicit same-original repair can revalidate and retains immutable events/checkpoints.
- Keep output/CRC/ratio/native raster and incremental metadata/edge limits. Canonical LRU is two, but separately unload nonlive engine sections/listeners/owners on EVERY settled command, including failure. Preserve the current display/checkpoint; roll back changed failed displays without guessed publication. Raster leases follow the clipped parent viewport. Inert owned intrinsic placeholders preserve authored one-axis/percentage geometry: never inject missing width/height attributes. READY requires actual decoded visible book assets, not placeholder natural dimensions. Bound native image/font/layout stabilization and verify the requested source element is clipped-visible before open/reflow/TOC readiness. Release offscreen actual URLs while retaining equivalent intrinsic geometry.
- EPUB.js consumes validated OPF/documents, never original ZIP bytes. Pin native `blobUrl` XHTML transport and XMLSerializer; preserve body namespaces/tree/text/IDs. Keep independent inert HTML head and authored/generated style rawtext guards, early CSP, strict fetching/NAV/NCX roles and no-scripts sandbox. Reader font styles use XHTML namespace and WeakMap ownership, not a book-controllable element ID.
- Pinned 0.3.93 seams own unload/orientation/URL cleanup, queue stop before destroy, rejection of unresolved NAV/`displayerror` deferreds and incorrectly typed `getContents` array. Reflow retains logical anchor but refreshes derived page metrics and never publishes. Visible-word activity uses the legacy combined-CFI range, not two collapsed ranges (image endpoints can return null).
- Startup selects access before asynchronous cleanup and fences queued access application by generation. Ready requires latest access durably applied; old completion cannot override a new selection. Provider projection and the native frame/progress are immediately masked on account/key changes.
- Checkpoint+immutable progress event commit atomically. A forward activity candidate has one stable interval/event ID and frozen payload. Committed credit consumes its interval before later engine/checkpoint publication; exact retries are durable no-ops, collisions reject, failed credit commits do not consume it. Add no idle/reread heuristics.
- Persist CAS decisions before fetching details. Missing details are `server:null`/needs-refresh, never invented ReadingState. Shared bounded detail budget and delivery-first lease fairness protect independent activity. Auth/abort/epoch/lease fences still stop replay; explicit choices require fresh state and retain history/new IDs.
- ZIP flags are method-specific: DEFLATE permits option bits 1/2 plus descriptor/UTF-8; STORE permits only descriptor/UTF-8. Encryption/reserved bits, ZIP64, local/central mismatch, actual limits and CRC remain fail-closed.
- Retirement deletes only the documented legacy allowlist. `done` is terminal; failed precache/cleanup never resets new books/events. Handshake tuple is protocol 1 / browser schema 2 / events 1. Worker modules use structural host types, not a conflicting WebWorker global lib reference.

Private copies/profiles/results stay in authorized scratch, without traces/screenshots/shared content.
