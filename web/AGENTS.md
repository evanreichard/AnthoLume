# Production frontend

- `src/reading/**` is reader-owned; `src/api/schema.gen.ts` is backend-generated. Consume only the reader's `index.ts` handoff. Frontend alone owns package/lock files.
- Use `PageHeader` from `src/ui.tsx` for top-level route titles. Library, Insights, and Book Detail use the shared shell width and gutters; constrain individual elements when needed, not the entire page.
- Query data is disposable. Cancel/clear it before identity transitions; the reader alone owns cached EPUBs, durable checkpoints, events and receipts. Keep credentials/CSRF out of browser persistence.
- `openapi-fetch` consumes error bodies even with `parseAs: 'stream'`: validate/forward the untrusted result `error`, not `response.json()` twice. Event delivery never expires sessions; only the reader's validated Problem + current durable lease may call `onSessionExpired`. A stale lease need not change the frontend account epoch. Read/binary 401 handling requires current-account checks and a validated authentication Problem.
- Browser acceptance uses `tests/server` with actual production Go router/database and HTTP credentials, synthetic files/DB, `-mod=readonly`, and owned loopback ports. Use an automatic test-scoped fixture for fresh Go process isolation; a module-level `beforeEach` in a cached fixture module does not cover every spec. File-controlled faults never add production fixture endpoints.
- Retirement URLs carry only a bounded opaque document ID through login. Construct the BookRef from the authenticated exact-origin account; wait for the reader's public ready/resume-account projection before immediate cached-book opening. Hide prior expired-account projections while intent awaits authentication. Worker retirement is best-effort and never gates reading or saving.
- Keep one recovery presenter/provider coordinator. Reader recovery is a bounded compact dock with native-dialog details; reserve its measured height in the frontend reader viewport so it cannot cover reader panels/footer. Test Appearance/Contents/footer and recovery center hit-testing plus unforced clicks at 320/390/landscape, not only visibility.
- Library sort is URL-owned and applied by the shared list before pagination; Library Add book uploads to the server; previously imported local books are export-only. Named 44px Clear search clears draft plus applied `q`, preserves sort and focuses the input; native UA decoration stays hidden. Successful durable actions focus a surviving heading after projection/navigation; cancel restores only a connected opener.
- Large-book source/staging/hash/resource ownership stays in `reading`. Reader lifecycle cancels cache population through its AbortSignal; cache eviction never edits queued progress. `BookRow.bytes === null` is valid: check public availability, actual source/manifest/chunk backing and native reading, never a whole-blob shim. Small fixtures do not qualify large-book parity; rerun joint integration after reader completion.
- Keep `/sw.js` as a one-time retirement endpoint, not a newly registered offline worker. Retire only owned shell caches; preserve book data, queued events, and unrelated storage.
