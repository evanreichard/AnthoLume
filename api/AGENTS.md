# HTTP boundaries

- `openapi.yaml` is the `/api/v1` contract. From the repo root, use `npm --prefix web ci`, then `make generate` and `make check_generation`. `generate.sh [output-root]` emits Go bindings, TypeScript types and standalone JSON response guards. Declare wire shapes and limits in the schema; keep cross-field and request-specific checks in the client.
- KOSync, SyncNinja and OPDS have their own wire formats. Share identity and reading operations, not handlers. For example, preserve KO’s optional device ID and numeric timestamp; expose an unidentified writer as `null` in web reading state and omit it from manageable devices. Test protocol changes through both the writing and consuming clients.
- In Gin handlers pass `c.Request.Context()` (or `requestContext(ctx)`) to storage. Bound incoming bodies before binding; decode opaque path IDs exactly once. Preserve the web origin, CSRF, account and generation checks in `web-validation.go`. Return safe Problems and keep credentials and request bodies out of logs. Apply `setCoverResponseHeaders` to cover responses, including OPDS fallbacks.
- Keep admin operations under `/api/v1/admin/`. Web middleware authenticates once per request and gates every matched admin route on that role; demotion or session revocation takes effect on the next request. Use transactions for atomicity, not role rechecks. Preserve operation-specific restrictions. Use `attachCatalogFile` for upload/import placement; KOReader partial MD5 identifies the book, full MD5 is metadata. Preserve existing history and edited metadata.
- Book Matcher uses the normal authenticated document list. For `include=matches`, load links in one query after pagination in the same read transaction; return an empty array for unlinked documents. Provider lookup and link changes use the usual session and write protections; changing the default provider remains admin-only. Release SQLite before paced provider I/O. Matcher confirmation rechecks the link and current metadata inside one write transaction; an identical link is a no-op, and only verified editions supply ISBNs. The lookup engine emits one outcome per document; the handler encodes and flushes it. An upstream failure is not an empty list, and a work-level ISBN hit is not edition evidence.
- Bind metadata catalogs once in `newMetadataCatalogs`; use the binding for availability and catalog calls, and let adapters own artwork fetching. Keep saved provider identities independent of credentials so links remain readable and removable when a catalog is unconfigured. Review an existing source through its confirmed provider and work ID, not the configured default. Recheck the link after catalog I/O and inside the apply transaction, without resolving or writing it again.
- Preview a backup from one catalog snapshot, then release SQLite before walking files. Validate exports against their archived database. Upgrade the staged backup with the normal Goose migrations before publishing; use local root mappings, never overwrite colliding live files, and rotate the reading generation before publishing. See `restore-migrations_test.go`, `restore_generation_test.go` and `backup-format_test.go`.
