# HTTP boundaries

- `openapi.yaml` is the `/api/v1` contract. From the repo root, use `npm --prefix web ci`, then `make generate` and `make check_generation`. Edit the schema or generator, not generated Go/TypeScript.
- KOSync, SyncNinja and OPDS have their own wire formats. Share identity and reading operations, not handlers. For example, preserve KO’s optional device ID and numeric timestamp; expose an unidentified writer as `null` in web reading state and omit it from manageable devices. Test protocol changes through both the writing and consuming clients.
- In Gin handlers pass `c.Request.Context()` (or `requestContext(ctx)`) to storage. Bound incoming bodies before binding; decode opaque path IDs exactly once. Preserve the web origin, CSRF, account and generation checks in `web-validation.go`. Return safe Problems and keep credentials and request bodies out of logs. Apply `setCoverResponseHeaders` to cover responses, including OPDS fallbacks.
- For ordinary admin database writes use `adminTransaction`: recheck role and session in the transaction that mutates state. Use `attachCatalogFile` for upload/import placement; KOReader partial MD5 identifies the book, full MD5 is metadata. Preserve existing history and edited metadata.
- Preview a backup from one catalog snapshot, then release SQLite before walking files. Validate exports against their archived database. Restore only after schema recognition and validation in staging; use local root mappings, never overwrite colliding live files, and rotate the reading generation before publishing. See `restore-migrations_test.go`, `restore_generation_test.go` and `backup-format_test.go`.
