# API boundary

- `openapi.yaml` defines `/api/v1`. Keep KOSync wire compatibility in the separate adapter: opaque positions, numeric accepted timestamps, and account-scoped aliases. From the repo root, run `make generate` and `make check_generation` with locked web dependencies. Generate Go/TS rather than editing them; TypeScript binary types require the Blob transform.
- Strict Gin supplies a pooled `*gin.Context`: unwrap `Request.Context()` before database/reading operations. Keep fallback disabled. Apply byte/media/UTF-8/duplicate-key checks before the validator and retain its validated body for strict binding.
- Route on escaped paths, decode opaque IDs once with `PathUnescape` (not query decoding), and decode validator path parameters before character-length checks. Preserve slash/plus/percent and 128-character Unicode IDs.
- `format: uuid` alone is not runtime validation in the selected validator. Keep the explicit event-ID pattern and string Go type so validation does not rewrite identity text.
- The JSON web API and external protocol adapters share identity/reading operations, never handlers. Preserve KO/OPDS wire contracts. Serve the React shell only for known navigation paths. Keep the Go allowlist and Vite navigation in sync.
- Metadata cover previews use numeric Open Library IDs and bounded JPEG responses; redirect targets stay on the Open Library / Internet Archive host allowlist. Keep remote cover selection in the editor draft until save.
- All cover routes (including OPDS and its fallback) apply `setCoverResponseHeaders`; serving bytes as an image does not make top-level SVG inert. Preserve bytes/MIME and allow image display, not script execution, document embedding or external resources. Run `bash api/check-cover-browser.sh` with installed Chromium for the real-browser regression.
- Apply shared Retry-After policy to 429/503 in every error renderer and direct legacy credential rejection; do not collapse credential work overload into a registration 400.
- Admin mutations recheck the acting administrator and session token in the write transaction. User deletion requires a verified, private database snapshot before any account rows are removed. Native maintenance jobs persist bounded status history, coalesce active work by kind, and run with server-owned deadlines rather than request contexts. React owns Administration; admin mutations are versioned API calls. Backups use a separate WAL reader; full backups serialize with library-file mutations, not reading or sync. Writer and restore share archive limits and publish only verified backups atomically. Only restore takes the exclusive request gate. Validate schema, save a recovery snapshot, and install files at new paths before swapping the database. Rotate the reading generation inside the staged copy so old session cookies and event submissions fail as soon as restore commits.
- Versioned errors are safe Problems. Logs must not contain request bodies, cookies, passwords or CSRF tokens, including panic recovery.
